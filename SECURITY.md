# Security policy

Proof Fitness is currently an early-stage local-first project.

Please do not publish a security vulnerability in a public issue. Contact the maintainers privately through the repository’s security-reporting channel once one is configured.

Useful reports include:

- Browser-storage data exposure.
- Import-file validation bypasses.
- Cross-site scripting.
- Service-worker cache poisoning.
- Unsafe external-link handling.
- Unexpected collection or transmission of personal data.

Never include real health records or other sensitive personal data in a report.
