# Prototype v0.3 — Approved Experience Improvements

This amendment records the approved changes added after benchmarking leading fitness products.

## Included

- Bricolage Grotesque display typography with Inter for interface text.
- Last time / Today / Next eligible context on the active exercise screen.
- Full form guidance on first appearance, compact refresher on later appearances.
- Calibration converted from a full page into a bottom sheet.
- Curated exercise substitutions with separate future progression histories.
- Three-tap pre-workout readiness state.
- Weekly coaching review that produces one neutral recommendation.
- Persistent active-workout strip when the workout is minimised.
- Ten-second rest warning plus the existing completion ringtone and vibration.
- Shorter four-step onboarding; food exclusions, waist and reminders move to contextual setup.

## Still intentionally excluded

- Production persistence, service worker and IndexedDB.
- Native lock-screen Live Activities.
- Owned exercise-video production.
- Medical recovery diagnosis.
- Automatic programme or nutrition changes without confirmation.
