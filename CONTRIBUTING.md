# Contributing to Proof Fitness

Thank you for helping improve Proof Fitness.

## Development setup

```bash
npm install
npm run dev
```

Before submitting a change:

```bash
npm run check
npm run build
```

## Contribution principles

- Preserve the local-first product direction.
- Keep workout logging deliberately minimal.
- Do not add guilt-based language, punishment mechanics, or streak pressure around safety.
- Treat Nigerian foods as first-class meal options.
- Never silently change a user’s active workout or progression load.
- Keep pull-up programming conditional on confirmed equipment availability.
- Maintain keyboard, screen-reader, reduced-motion, and touch-target accessibility.

## Pull requests

A useful pull request should include:

- A clear problem statement.
- The user-facing behaviour that changed.
- Screenshots for visual changes.
- Tests or manual verification steps.
- Any migration or compatibility considerations.

Keep unrelated refactors out of feature pull requests where practical.

## Issues

For bugs, include:

- Browser and operating system.
- Screen size or device.
- Reproduction steps.
- Expected and actual behaviour.
- Whether the app was installed or running in a browser tab.
